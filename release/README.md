# 投递文本助手

这是一个本地运行的 Windows 桌面小工具，用来管理投递表单里反复填写的文本。你可以把姓名、联系方式、实习经历、科研经历、项目描述等内容提前写进 JSON 资料库，然后在投递网页里点击输入框，再点本工具里的快捷按钮。

## 直接使用

如果已经打包成功，双击运行：

```powershell
release\ResumeQuickPaste.exe
```

使用流程：

1. 先在浏览器或招聘系统里点击需要填写的输入框。
2. 回到本工具，点击快捷按钮。
3. 默认情况下，程序会把文本复制到剪贴板并选择该条目，不会自动粘贴。
4. 如果勾选“点击后自动粘贴”，普通点击会尝试粘贴到刚才的输入框。
5. 如果保持默认关闭自动粘贴，按住 `Ctrl` 再点击快捷按钮，会临时强制自动粘贴。
6. 按住 `Shift` 点击快捷按钮可以只选择条目，不复制也不粘贴；连续 `Shift+点击` 可多选，用于批量删除。
7. 如果自动粘贴仍不适配目标页面，可以按住快捷按钮拖到目标输入框后松开，程序会尝试直接模拟键盘输入。拖动时会有一个浅色的小标签跟随鼠标，提示当前拖动的是哪条文本。

顶部的“窗口置顶”默认开启，适合单屏投递时让工具一直浮在网页上方。你也可以关闭它，让窗口按普通方式切换。

“点击后自动粘贴”默认关闭。这样普通点击不会误填到网页里；需要临时自动粘贴时，按住 `Ctrl` 再点击快捷按钮。

## 编辑快捷文本

- 快捷按钮用于快速粘贴或复制，按钮会根据键名长短自动排列。
- 同一个分组里的按钮会显示在同一个圆角框内，框左上角显示分组名。
- 点击某个快捷按钮后，窗口底部会显示当前条目，并出现“编辑”“删除”按钮。
- `Ctrl+点击` 会强制自动粘贴，适合平时关闭自动粘贴、需要填入时临时触发。
- `Shift+点击` 会多选条目；多选时“编辑”按钮会变浅并禁用，“删除”会批量删除已选条目。
- 选中一个或多个条目后，点击“分组”可以调整它们所属的分组。弹窗里可以从下拉框选择现有分组，也可以输入一个新分组名来创建新分组。
- 点击“编辑”会弹出小窗口修改键名、分组和值。
- 点击“新增条目”会弹出小窗口添加新的键值对，并可以直接填写分组。
- 点击“删除”会从当前 JSON 中删除该键值对。
- 搜索框会同时搜索键名和文本内容。

## JSON 应该放在哪里

如果你双击使用的是打包版：

```text
release\ResumeQuickPaste.exe
```

AI 生成的 `.json` 文件应该放在 exe 同级的 `databases` 文件夹，也就是当前项目里的：

```text
release\databases
```

如果你把 `ResumeQuickPaste.exe` 整个复制到别的地方使用，规则仍然一样：JSON 放在 exe 同级的 `databases` 文件夹。

如果你是开发者，用源码运行：

```powershell
python app.py
```

那么 JSON 应该放在项目根目录的：

```text
databases
```

简历 PDF、Word 或图片只给 AI 解析用，程序本身不会直接读取简历文件。程序只读取 `databases` 里的 `.json` 资料库。

## 管理多份资料库

程序会读取当前运行位置下的：

```text
databases
```

每个 `.json` 文件就是一份资料库。你可以在程序顶部新建、重命名、删除资料库，也可以直接用文本编辑器修改 JSON。

推荐使用分组 JSON 格式：

```json
{
  "groups": {
    "基本信息": {
      "姓名": "XXX",
      "邮箱": "XXX",
      "求职方向": "XXX"
    },
    "科研项目A": {
      "科研经历-科研项目A-经历名称": "XXX",
      "科研经历-科研项目A-经历角色": "XXX",
      "科研经历-科研项目A-经历详情": "论文内容：XXX。1) XXX。2) XXX。3) XXX。"
    },
    "技能证书": {
      "技能-编程语言": "XXX",
      "技能-工具": "XXX"
    }
  }
}
```

为了兼容旧文件，程序仍可以读取旧版扁平 JSON，例如 `{ "姓名": "XXX" }`。但从程序里新增、编辑或保存后，会统一写成上面的 `groups` 分组格式。

## 放置不同岗位简历

可以把不同投递方向的简历放在：

```text
resumes_by_role
```

建议按投递场景建子文件夹，例如“数据分析岗位”“科研实习岗位”“产品运营岗位”。一份简历对应一个场景，也对应一个 JSON 资料库。

## 让 AI 从简历生成 JSON

项目根目录有：

```text
AI_PROMPT_简历生成快捷文本JSON.txt
```

你可以把这个提示词发给 AI，同时提供你的若干份简历，让 AI 按“一份简历一个 JSON”的规则生成资料库。生成后把 `.json` 文件放进对应的 `databases` 文件夹，再重启或切换资料库即可使用。

提示词会要求 AI 先询问你要解析哪些内容；你可以直接回复“默认”。默认方案是不解析教育经历、不解析任何经历时间，只解析基本信息、经历内容、技能证书等适合粘贴到投递表单里的内容。

提示词还会要求 AI 把每段实习、科研或项目经历拆成“经历名称、经历角色、经历详情”，并默认按经历或项目分组。分组名优先使用项目名、课题简称、公司/岗位短名、竞赛名，或其他能识别该经历的短名称。同一份简历不会被拆成多个岗位 JSON；多 JSON 用来管理多份不同简历。

## 重新打包 exe

如果你修改了程序代码，可以在 PowerShell 中运行：

```powershell
.\build_exe.ps1
```

脚本会使用 PyInstaller 生成：

```text
release\ResumeQuickPaste.exe
```

如果没有 PyInstaller，脚本会自动用 pip 安装。打包只是为了获得 exe；日常使用时不需要配置 Python 环境。

## 常见问题

自动粘贴没有生效：这是某些浏览器、招聘系统或权限设置导致的。程序已经把内容复制到了剪贴板，请在输入框里按 `Ctrl+V`；也可以按住快捷按钮拖到目标输入框松开，尝试拖动输入。

找不到刚才的输入框：请先点击目标输入框，再点击快捷按钮。建议保持“窗口置顶”打开。

JSON 打不开：通常是格式错误。请检查是否使用双引号、是否有多余逗号、换行是否写成 `\n`。

`app_settings.json` 有用吗：有用，但用户不需要手动配置。它是程序自动生成的运行设置文件，用来记录窗口置顶、自动粘贴、上次选择的资料库等偏好。删除后程序会在下次启动时按默认设置重新生成。

隐私说明：本工具只读写本地文件，不上传简历或投递信息。
