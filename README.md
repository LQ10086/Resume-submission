# 投递文本助手

这是一个本地运行的 Windows 桌面小工具，用来管理投递表单里反复填写的文本。你可以把姓名、联系方式、实习经历、科研经历、项目描述等内容提前写进 JSON 资料库，然后在投递网页里点击输入框，再点本工具里的快捷按钮。

## 直接使用

如果已经打包成功，双击运行：

```powershell
release\ResumeQuickPaste.exe
```

使用流程：

1. 先在浏览器或招聘系统里点击需要填写的输入框。
2. 回到本工具，点击快捷按钮。
3. 程序会先把文本复制到剪贴板，再尝试自动粘贴到刚才的输入框。
4. 如果网页或系统拦截了自动粘贴，内容仍然已经复制好，在目标输入框按 `Ctrl+V` 即可。
5. 如果自动粘贴仍不适配目标页面，可以按住快捷按钮拖到目标输入框后松开，程序会尝试直接模拟键盘输入。

顶部的“窗口置顶”默认开启，适合单屏投递时让工具一直浮在网页上方。你也可以关闭它，让窗口按普通方式切换。

## 编辑快捷文本

- 快捷按钮用于快速粘贴或复制，按钮会根据键名长短自动排列。
- 点击某个快捷按钮后，窗口底部会显示当前条目，并出现“编辑”“删除”按钮。
- 点击“编辑”会弹出小窗口修改键名和值。
- 点击“新增条目”会弹出小窗口添加新的键值对。
- 点击“删除”会从当前 JSON 中删除该键值对。
- 搜索框会同时搜索键名和文本内容。

## 管理多份资料库

## JSON 应该放在哪里

如果你双击使用的是打包版：

```text
release\ResumeQuickPaste.exe
```

AI 生成的 `.json` 文件应该放在 exe 同级的 `databases` 文件夹，也就是当前项目里的：

```text
release\databases
```

如果你把 `ResumeQuickPaste.exe` 整个复制到别的地方使用，规则仍然一样：JSON 放在 exe 同级的 `databases` 文件夹。

如果你是开发者，用源码运行：

```powershell
python app.py
```

那么 JSON 应该放在项目根目录的：

```text
databases
```

简历 PDF、Word 或图片只给 AI 解析用，程序本身不会直接读取简历文件。程序只读取 `databases` 里的 `.json` 资料库。

## 管理多份资料库

程序会读取当前运行位置下的：

```text
databases
```

每个 `.json` 文件就是一份资料库。你可以在程序顶部新建、重命名、删除资料库，也可以直接用文本编辑器修改 JSON。

JSON 格式示例：

```json
{
  "姓名": "张三",
  "邮箱": "zhangsan@example.com",
  "科研经历-科研项目A-经历名称": "某科研项目 | 主要参与",
  "科研经历-科研项目A-经历角色": "主要参与人",
  "科研经历-科研项目A-经历详情": "论文内容：围绕某个研究问题完成方法设计、实验验证和结果分析。1) 梳理背景。2) 参与实现。3) 总结结果。"
}
```

## 放置不同岗位简历

可以把不同投递方向的简历放在：

```text
resumes_by_role
```

建议按投递场景建子文件夹，例如“数据分析岗位”“科研实习岗位”“产品运营岗位”。项目里已经放了这些空文件夹的说明文件。一份简历对应一个场景，也对应一个 JSON 资料库。

## 让 AI 从简历生成 JSON

项目根目录有：

```text
AI_PROMPT_简历生成快捷文本JSON.txt
```

你可以把这个提示词发给 AI，同时提供你的若干份简历，让 AI 按“一份简历一个 JSON”的规则生成资料库。生成后把 `.json` 文件放进 `databases` 文件夹，再重启或切换资料库即可使用。

提示词会要求 AI 先询问你要解析哪些内容；你可以直接回复“默认”。默认方案是不解析教育经历、不解析任何经历时间，只解析基本信息、经历内容、技能证书等适合粘贴到投递表单里的内容。

提示词还会要求 AI 把每段实习、科研或项目经历拆成“经历名称、经历角色、经历详情”，并在键名里加入项目或任务短标识，方便你在快捷按钮里快速识别。同一份简历不会被拆成多个岗位 JSON；多 JSON 用来管理多份不同简历。

## 重新打包 exe

如果你修改了程序代码，可以在 PowerShell 中运行：

```powershell
.\build_exe.ps1
```

脚本会使用 PyInstaller 生成：

```text
release\ResumeQuickPaste.exe
```

如果没有 PyInstaller，脚本会自动用 pip 安装。打包只是为了获得 exe；日常使用时不需要配置 Python 环境。

## 常见问题

自动粘贴没有生效：这是某些浏览器、招聘系统或权限设置导致的。程序已经把内容复制到了剪贴板，请在输入框里按 `Ctrl+V`；也可以按住快捷按钮拖到目标输入框松开，尝试拖动输入。

找不到刚才的输入框：请先点击目标输入框，再点击快捷按钮。建议保持“窗口置顶”打开。

JSON 打不开：通常是格式错误。请检查是否使用双引号、是否有多余逗号、换行是否写成 `\n`。

隐私说明：本工具只读写本地文件，不上传简历或投递信息。

`app_settings.json` 是程序自动生成的运行设置文件，用来记录窗口置顶、自动粘贴、上次选择的资料库等偏好。用户不需要手动配置这个文件；删除后程序会在下次启动时自动按默认设置重新生成。
